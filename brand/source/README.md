# Source material

`avatar-phosphor95-48.png` is the **master avatar**: the exact image GNOME's lock screen shows (`avatar-default-symbolic` in the Phosphor95 icon theme). Logo assets are derived from it at integer scales only. The rest is reference: the SVG of the same drawing, the Chicago95 originals, and snapshots of the theme's palette and system config.
